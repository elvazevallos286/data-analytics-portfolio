# Airbnb Seattle Market Analysis | Tableau

## Project Overview
This project analyzes Airbnb listings in Seattle, Washington, using Tableau to explore how property size and location influence nightly rental prices.

## Business Questions
- How do Airbnb prices vary by the number of bedrooms?
- Which ZIP codes have the highest average rental prices?
- What property sizes are most common in Seattle?

## Key Insights
- **Property Size:** Average prices range from $96.20 for one-bedroom properties to $584.80 for six-bedroom properties.
- **Market Composition:** One-bedroom listings are the most common, with 1,811 properties in the dataset.
- **Location:** Average Airbnb prices vary significantly across Seattle ZIP codes, with some areas costing more than three times as much as others.
