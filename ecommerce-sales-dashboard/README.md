# E-Commerce Sales Performance Dashboard (2021–2022)

## Project Overview
An interactive e-commerce sales dashboard built in Google Looker Studio to explore revenue, customer activity, product performance, and marketing campaigns.

## Tools Used
- Google Looker Studio
- CSV datasets
- Data cleaning and calculated fields

## Skills Demonstrated
- Data visualization and dashboard design
- Interactive filters and scorecards
- Date formatting and data preparation
- Troubleshooting data quality issues

## Key Findings
- Total sales revenue: $2,068 (all dates)
- Unique buyers: 29 (all dates)

## Known Limitation
The unique buyer count requires further validation when a fixed date range is applied.
