# 🏀 NBA Games Analysis Dashboard (2003–2022)

## Project Overview

This project explores NBA game data from 2003 to 2022 using Google Looker Studio. I created an interactive dashboard to visualize game statistics, team participation, seasonal trends, and home versus away wins.

This project was completed as part of my Data Analytics training with Tech-Moms.

## Tools & Technologies

- Google Looker Studio
- CSV datasets
- Data Blending and JOIN operations
- Calculated Fields
- Data Visualization

## Dashboard Features

- **Total NBA Games:** 26,651
- **Number of Teams:** 30
- **Total Seasons:** 20
- **Total Points Scored:** 5,419,151
- NBA Games by Season
- Home vs. Away Wins
- Top 10 NBA Teams by Home Games
- Interactive Filters

## Skills Demonstrated

- Connecting and preparing CSV data sources
- Combining datasets using Data Blending
- Creating calculated metrics
- Building interactive dashboards
- Visualizing and interpreting sports data
- Troubleshooting data filters and chart configurations

## Data Source

NBA Games Dataset by nathanlauga on Kaggle.
